# Dar El Halwa

## Aperçu
Site web vitrine pour une pâtisserie tunisienne traditionnelle. 
Le site présente les spécialités de la maison : Baklawa, Kaak Warka et Makroudh.
C'est un projet de Développement Web 1 - Atelier HTML5.

## Fonctionnalités
- Fonctionnalité 1 : Page d'accueil avec présentation de la pâtisserie
- Fonctionnalité 2 : Page Produits avec liste et prix des gâteaux
- Fonctionnalité 3 : Page Contact avec formulaire de commande

## Technologies
- Frontend : HTML5 (version actuelle sans CSS)
- Structure : 3 pages liées entre elles avec la balise <a>
- Outil : VS Code

## Type html5 utilisé

| Nom champ | Son Rôle |
| :--- | :--- |
| header | Contient le logo et le titre du site |
| nav | Barre de navigation pour passer entre les pages |
| main | Partie principale de chaque page |
| h1, h2, h3 | Titres pour les sections |
| p | Paragraphes de texte pour décrire les produits |
| ul / li | Liste des ingrédients et des produits |
| table, tr, td | Tableau pour afficher les prix |
| form | Formulaire de contact client |
| input | Champs pour nom, email et message |
| footer | Pied de page avec les informations de contact |
